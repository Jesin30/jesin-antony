## 📌 Project Overview
This project is a high-performance, responsive e-commerce product catalog web application built for the InternTrack internship practical assessment. It features dynamic product filtering, real-time cart state management, checkout summary calculation, and interactive modal dialogs.

---

## ✅ Completed Tasks Checklist

- [x] **Task 1: Build Responsive Product Catalog & Filters**
  - Dynamic category switching (All, Electronics, Fashion, Accessories, Gadgets).
  - Search filter with instant debounced input matching.
  - Responsive flex/grid layout that adapts from mobile screens to 4K displays.
  - Product price tags, ratings, and stock status badges.

- [x] **Task 2: Implement Real-Time Cart State Management**
  - Add to cart with animated toast feedback.
  - Interactive sliding Cart Drawer with item increment/decrement/remove controls.
  - Real-time subtotal, GST (18%), discount codes, and final order total calculations.
  - Persistent state in browser `localStorage` so items remain saved on reload.

- [x] **Task 3: Connect Sample API & Push to GitHub**
  - Asynchronous mock REST API loader with realistic loading skeletons.
  - Clean modular code structure (`index.html`, `styles.css`, `app.js`).
  - Production-ready Git repository with comprehensive documentation.

| Feature | Description |
